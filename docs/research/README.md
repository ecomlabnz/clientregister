# Research

Notes on the field this register is built into. Public material only — vendor
websites, company registers, review sites — read on the date each file names.

Two rules for anything filed here:

- **No client data.** The standing rule applies to this folder like every other.
- **Say where each claim came from, and when.** A competitor's marketing page is
  evidence of what they claim, not of what their product does; a page read in
  August is not evidence about October. Files here carry their read date in the
  filename so that stays obvious.

Nothing in this folder is quoted in `docs/marketing.md`. Comparative claims made
from someone else's marketing copy are not worth putting in front of a
prospective client — what this material is for is deciding what to build.
